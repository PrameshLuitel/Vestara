# **App Name**: Vestara: Sultry Market Muse

## Core Features:

- Homepage UI: Homepage design with a white, grey, and minimalistic aesthetic, inspired by xAI's homepage but with stock market elements. Placeholders for data and graphs will be used.
- Chatbot UI: A chatbot interface with a placeholder.
- Predictive Suite Tab: Dedicated 'Predictive Suite' tab for accessing graph predictions. Placeholders for data and graphs will be used.
- Graph Predictions Display: Display graph predictions, trained externally (e.g., on Colab), as graphs on the website. Historic data will also be saved daily. Placeholders for data and graphs will be used.

## Style Guidelines:

- Primary color: White for a clean and minimalistic look.
- Secondary color: Light grey (#D3D3D3) for backgrounds and less important UI elements.
- Accent color: Subtle stock market-related colors (e.g., greens and reds) for positive and negative trends.
- Headline font: 'Roboto', a modern sans-serif for clear headings.
- Body font: 'Open Sans', a legible sans-serif for data display and text.
- Use clear, data-driven icons to represent different market sectors and data points.
- Subtle animations for graph updates and data transitions to enhance user experience.
- Tab-based layout for easy navigation between the Chatbot and Predictive Suite.
